### Selected work

**[LGU - Spatial Decision Support System](https://github.com/borkangole/LGU-SDSS)** — Desktop GIS system any municipality can use by uploading its own boundaries, hazard maps, and CBMS data. Maps social vulnerability, barangay capacity, and household hazard exposure, plus a k-modes household typology. Piloted in San Miguel, Iloilo.<br>
<sub>React · Flask · Python · GeoPandas · SQLite · Leaflet</sub>

**[Liftmark](https://github.com/borkangole/Liftmark)** — Workout tracker that detects plateaus, explains why a lift has stalled, and maps muscle recovery. Android beta available.<br>
<sub>React Native · Expo · TypeScript · SQLite</sub>

**[Coral Vision](https://github.com/borkangole/Coral-Vision)** — Mobile app that identifies coral species on-device and geo-tags each find for reef monitoring.<br>
<sub>React Native · Expo · TensorFlow Lite · Python</sub>

**[TPPG Portal](https://tppg-portal-updated-production.up.railway.app/)** — Role-based real estate platform with agent hierarchy, listings, and commission computation.<br>
<sub>Node.js · Express · Supabase · PostgreSQL</sub>

**[TPPG Public Website](https://thepremierpropertygroup.vercel.app/)** — Buyer-facing property search with a map explorer and lead capture.<br>
